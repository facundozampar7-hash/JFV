Nuestra historia

Un taller con corazón de imprenta

JFV nació de las ganas de ayudar a otros emprendedores a mostrarse mejor: una tarjeta que se sienta profesional, un estampado que se luzca en la primera lavada, una etiqueta que haga que un producto se vea listo para vender. Cada pedido lo armamos a mano, revisando cada detalle antes de que llegue a tus manos.

  • ✓ Diseño gráfico personalizado para cada cliente
  • ✓ Materiales elegidos para que el resultado dure
  • ✓ Acompañamiento desde la idea hasta la entrega
